# 接入用例：计划任务与多步骤运行

本页展示 `plan.update`、`task.*`、`reasoning.*`、`tool.*`、`content.*` 在多步骤任务中的组合方式。

## 1. 计划与多任务：Query + Plan + Tasks

适合“先检索，再写总结”这类分步骤任务。

```json
// POST /api/query
{
  "requestId": "req_003",
  "chatId": "c_01",
  "agentKey": "auto",
  "role": "user",
  "message": "帮我先查资料，再写一段总结。要求：先列出检索关键词，再给 5 条要点，最后给 1 段总结。",
  "scene": { "url": "https://app.example.com/chat" },
  "stream": true
}
```
